# Analisis Aplikasi - Pertemuan 1

## Aplikasi yang Diamati
Aplikasi Mobile Pengelolaan Tugas Akademik (Task Management).

## Pengguna (Target User)
Mahasiswa dan pelajar yang membutuhkan manajemen waktu harian serta pencatatan tugas kuliah.

## Tiga Fitur Utama
1. **Manajemen Tugas**: Menambah, mengubah, dan menghapus daftar tugas kuliah.
2. **Pengingat / Notifikasi**: Pemberitahuan tenggat waktu (*deadline*) tugas.
3. **Kategori Mata Kuliah**: Pengelompokan tugas berdasarkan nama mata kuliah.

## Usulan Perbaikan
Menambahkan fitur mode gelap (*dark mode*) otomatis demi kenyamanan pengguna saat mengakses aplikasi di malam hari.
